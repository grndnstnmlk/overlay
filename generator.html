💡 Kenapa Tombol Hotkey ('S' & 'T') Tidak Berfungsi di TikTok Live Studio?
  • Di TikTok Live Studio & OBS, sumber "Tautan / Browser" berjalan di latar belakang (background CEF) yang terisolasi.
  • TikTok Live Studio mengunci input keyboard ke jendela utamanya atau ke game Anda, sehingga tombol S atau T tidak terkirim ke dalam halaman overlay.
  • Solusi Terbaik & Resmi: Gunakan link dengan parameter URL di atas! Cukup ubah link di pengaturan sumber TikTok Live Studio, overlay langsung berubah otomatis tanpa perlu tekan keyboard apapun.
  • Khusus OBS Studio: Jika memakai OBS, Anda bisa Klik Kanan sumber Browser -> pilih "Interact" (Interaksi), maka tombol S, T, dan klik mouse akan berfungsi penuh!

2. CARA PASANG DI TIKTOK LIVE STUDIO (VERSI VERTIKAL 1080 x 1920)
--------------------------------------------------------------------------------
1. Buka aplikasi TIKTOK LIVE STUDIO di PC/Laptop Anda.
2. Di bagian kanan atas atau pengaturan layar, pastikan format kanvas adalah:
   - Orientasi : Vertikal / Potret (9:16)
   - Resolusi  : 1080 x 1920
3. Pada panel "Sumber" (Sources), klik tombol "+ Tambahkan Sumber" (Add Source).
4. Pilih opsi "Tautan" (Link) atau "Browser".
5. Di kolom URL / Tautan, masukkan link berikut:
   https://grndnstnmlk.github.io/overlay/
6. Atur ukuran resolusi sumber:
   - Lebar (Width)  : 1080
   - Tinggi (Height): 1920
7. Centang opsi transparansi (jika ada), lalu klik "Terapkan" / "Simpan".

8. ATUR URUTAN LAYER (PENTING AGAR TIDAK KETUTUP):
   Urutkan layer dari PALING ATAS ke PALING BAWAH:
   ----------------------------------------------------------------------------
   [Layer 1 - PALING ATAS] : Browser (Overlay Vertikal)
                             -> Overlay ini transparan di bagian tengahnya.
   [Layer 2 - TENGAH]      : Tangkapan Layar Game / Layar HP MLBB (16:9)
                             -> Posisikan game tepat di dalam kotak panduan
                                bingkai tengah (di antara Y: 125px s/d 733px).
   [Layer 3 - BAWAH/OPSI]  : Kamera / Webcam Facecam (jika ada).
   [Layer 4 - PALING DASAR]: Background / Wallpaper (opsional).
   ----------------------------------------------------------------------------

3. CARA PASANG DI OBS STUDIO / STREAMLABS (VERSI HORIZONTAL 1920 x 1080)
--------------------------------------------------------------------------------
1. Buka aplikasi OBS STUDIO atau Streamlabs Desktop.
2. Pada panel "Sources" (Sumber), klik ikon "+" -> Pilih "Browser".
3. Beri nama sumber (misalnya: "MLBB Promo Overlay"), lalu klik OK.
4. Pada kolom URL, masukkan:
   https://grndnstnmlk.github.io/overlay/overlay.html
   (Atau bisa centang "Local file" lalu Browse ke file overlay.html di laptop Anda).
5. Atur ukuran resolusi:
   - Width  : 1920
   - Height : 1080 (atau Height: 180 jika hanya ingin kotak banner tipis)
6. Centang:
   [v] Shutdown source when not visible
   [v] Refresh browser when scene becomes active
7. Klik OK. Overlay banner bawah akan langsung muncul di layar live stream!

4. PERINGATAN PENTING: MENGAPA TIKTOK MEMBERIKAN STRIKE
   "DIRECTING VIEWERS OFF-PLATFORM" & CARA MENCEGAHNYA
--------------------------------------------------------------------------------
TikTok memiliki bot AI OCR (Optical Character Recognition) yang memindai layar
live Anda secara real-time setiap beberapa menit. Jika mendeteksi salah satu
dari hal berikut, siaran akan langsung dibatasi / terkena pelanggaran:

X PEMICU UTAMA STRIKE TIKTOK:
1. Menampilkan teks link domain website langsung di layar (seperti: jagestore.shop,
   .com, .id, dll).
2. Menampilkan gambar barcode QR Code / QRIS langsung di layar secara terus-menerus.
3. Menulis kata "WhatsApp", "WA", "Discord", nomor telepon, atau nomor rekening bank.

V CARA RESMI & AMAN STREAMER TIKTOK (TIKTOK SAFE STRATEGY):
1. Arahkan Penonton ke "BIO PROFIL TIKTOK":
   TikTok SANGAT MENGIZINKAN Anda mengarahkan penonton ke Bio akun TikTok Anda sendiri!
   Oleh karena itu, overlay vertikal Anda sudah diubah menjadi:
   - "TOP UP DIAMOND: CEK LINK DI BIO PROFIL"
   - "ORDER JOKI / MABAR: VIA DM TIKTOK"
2. Pasang Link Website Anda di Bio TikTok:
   Buka profil akun TikTok Anda -> Edit Profil -> Masukkan link website
   (https://jagestore.shop atau linktree Anda) di kolom Situs Web (Website Bio).
3. Transaksi & QRIS via DM TikTok:
   Ketika penonton ingin order joki atau top up, katakan pada penonton:
   "Langsung DM TikTok ya guys atau klik link di bio profil!".
   Kirimkan foto QRIS atau link jagestore.shop di dalam obrolan DM TikTok tersebut.
   Ini 100% AMAN dan bebas dari deteksi bot AI siaran langsung!

--------------------------------------------------------------------------------
Widget ini dirancang khusus untuk memicu algoritma FYP TikTok Live agar siaran
Anda direkomendasikan ke lebih banyak penonton baru:

TOMBOL PINTAS KEYBOARD (HOTKEYS):
- Tekan 'T' : Sembunyikan / Tampilkan (Toggle) widget Tap-Tap Layar & Share.

              * Target Like Live (misal: 50.000 atau 100.000)
              * Jumlah Like Saat Ini
              * Harga Mabar VIP
